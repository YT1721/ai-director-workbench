# 服务通道 Adapter 目录

本目录承载视频服务通道 Adapter。

当前业务结构已同步到 `V7.0 Plus R1｜UCODE-9 + FLOW-NAV + VP-PRECISION-18`：

- 服务通道只接收已确认的 `final_execution` 正式视频包。
- 正式视频包保留 18 项导演级结构与完整可复制提示词，不允许降级为短提示词。
- 即梦手动通道只导出逐镜生产包、复制卡和结果导入目录，不自动操作网页。
- 即梦 CLI 通道只调用本机官方 `dreamina` 命令，使用用户自己已登录的 CLI 账号积分；不自动登录网页、不读取账号密码、不保存 Token。

历史 Seedance 状态演练只保留为旧数据兼容能力，不作为正式入口展示。通用聚合服务通道当前只做配置校验与映射预览，不会发送网络请求；真实视频目前只开放慧梦单镜低规格验收通道。

Milestone 5 / 6A 增加受控文本服务与图像服务：

- 慧梦文本主脑：兼容 OpenAI Chat Completions 格式，使用系统主文件作为内部规则底座。
- OpenAI 官方文本主脑：使用 Responses API，使用系统主文件作为内部规则底座。
- 慧梦 image-2 受控生图通道：用于人物基础图、服装图、场景设定图和单镜故事板图。只允许服务层通过准备状态、页面确认和本地 `.env` 配置后调用；自动测试必须使用伪造客户端，不发送真实网络请求。

文字创作主流程不再提供本地规则冒充 AI 分析。没有 API Key 时必须先配置真实文本通道，避免用占位草稿冒充导演级 AI 分析。

禁止在页面组件中直接调用 OpenAI、Seedance、第三方聚合平台或即梦网页。

Milestone 6 接入准备层已增加：

- 通用聚合服务通道的文档、价格来源、模型映射和字段映射登记。
- 本地预检：只检查配置完整度与密钥环境变量是否存在，不读取或回传密钥。
- Canonical Video Request 脱敏映射预览：保存预览快照，但不发送 HTTP 请求。
- 待提交队列切换服务通道后的本地重映射：重新检查能力和预算，不修改资产、故事板或视频提示词历史版本。
- 第三方响应样例本地演练：支持点路径字段和状态归一化；样例不保存，不下载结果。
- Atlas Cloud 禁用状态专属 Adapter：集中保存 Atlas Cloud 当前文档对应的 Host、任务 Endpoint、Bearer 鉴权、模型 ID、响应映射和按秒预算模板。
- Atlas Cloud 模板只生成本地映射预览；`uploadMedia` 素材上传、真实提交、轮询和结果下载仍未开放。
- 慧梦真实单镜通道：只允许 1 个镜头、1-15 秒、720p、预算已确认、页面逐次确认后提交；首次建议用 5 秒小样。查询和下载也必须显式点击。
- 即梦 CLI 账号积分通道：只允许已有分镜提示词的受控单镜任务；提交、查询和下载都必须页面确认，下载后绑定 Shot ID。

已经提交、完成或导入结果文件的队列禁止重映射，避免修改历史记录。

新增真实视频服务通道必须等用户提供目标聚合平台当时有效的官方 API 文档与价格页后再实现。
