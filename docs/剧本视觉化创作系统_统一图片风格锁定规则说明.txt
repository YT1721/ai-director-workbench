# 统一图片风格锁定规则说明

## 最终统一标准

### 1. 故事板图片风格

统一以参考图1、图2为唯一默认标准。

核心特征：

```text
白底 / 浅灰底高信息密度导演故事板说明板
黑白灰铅笔草稿镜头画面
局部彩色功能箭头与文字标注
分区清晰
信息密度高
支持 4格 / 6格 / 9格 / 12格
用于导演分镜表达、动作拆解、运镜提示和视频生成参考
```

废止：

```text
黑底导演执行页故事板
深色 UI 控制台故事板
无标注纯美术故事板
其他旧版故事板风格
```

### 2. 人物角色设定卡风格

统一以参考图3、图4为唯一默认标准。

核心特征：

```text
米白 / 奶油白 / 浅暖灰背景
高端杂志化真人角色资产板
影视角色 Bible 式排版
真人写实质感
主肖像
全身多角度视图
动作姿态参考
表情研究
发型 / 面部 / 服装 / 饰品 / 道具 / 配色细节
```

废止：

```text
简陋人物设定板
概念草图式人物卡
二次元 / 卡通人物卡
其他非参考图3、图4标准的人物卡
```

## 执行原则

```text
默认只使用这两套图片风格。
旧版风格不再作为前台默认或可选样式展示。
如历史项目需要，仅能归档，不得覆盖当前统一标准。
```
