《V7.0 Plus R1｜DIRECTOR-TECH PLUS 补充说明》

本次升级让“特写进”和“蒙太奇”从术语变成可执行规则。

一、特写进连接器

不是单纯推近，而是：

空间 / 人物关系
→ 人物状态
→ 物件 / 手部 / 表情细节
→ 情绪或信息被放大
→ 回到人物反应或进入下一镜

使用示例：
V7｜视频包｜EP01SC01｜SH003
要求：使用特写进连接器，从人物中景推进到手部物件特写，再回到人物眼神，强化心理压迫。

二、细节插入镜头

典型结构：

人物主镜头
→ 细节特写
→ 人物反应

可插入：
手部、眼神、杯子、烟雾、火焰、信件、照片、门把手、武器、衣物细节、破损物、产品细节等。

三、蒙太奇四类

1. 时间压缩蒙太奇
2. 心理联想蒙太奇
3. 信息积累蒙太奇
4. 隐喻蒙太奇

使用示例：
V7｜故事板｜EP01SC01｜SH004-SH009
要求：使用心理联想蒙太奇，通过人物表情、物件状态、烟雾扩散和环境细节表现角色焦虑。

四、物体状态隐喻

通过物件变化表达心理或剧情：

烟雾扩散 = 焦虑 / 隐秘 / 失控
火焰摇晃 = 危险 / 欲望 / 情绪不稳
墨滴扩散 = 污染 / 记忆侵入
照片烧毁 = 关系破裂 / 过去被抹除

五、镜头意义链

每一个蒙太奇或细节镜头都必须回答：

它为什么出现？
它承接上一镜什么？
它让观众联想到什么？
它如何推动情绪？
它如何进入下一镜？
